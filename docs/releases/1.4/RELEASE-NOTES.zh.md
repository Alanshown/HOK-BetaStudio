## 1.4 相比 1.3 的主要改动

### 模型、骨骼与动画导出

- 修复 issue #7 所涉及的 Mesh 资产缺少 FBX 导出入口：现在支持 OBJ 与 FBX。
- FBX 根据实际引用连接模型层级、骨骼、权重、形变、材质和可用动画；无关联骨骼的纯网格可以导出静态 FBX，不凭名称猜配动画。
- AnimationClip 在模型与骨架引用完整时可随关联模型导出 FBX；只导出所选片段。无可用引用时仍可导出 ANIM／曲线 JSON，并明确说明原因。
- 修复旧式动画默认片段遗漏、根节点曲线绑定、关闭动画仍收集旧式片段、覆盖控制器使用错误片段等问题。
- 修复骨骼节点同时挂载网格时部分 FBX 读取器无法识别的问题，分离几何节点时保持骨骼运动与形变轨道正确。
- 修复原生 FBX 长路径输出失败、中文／越南文目录下 DLL 加载问题；输出文件会校验，不再把未生成文件误报成功。
- 导出面板明确 OBJ 是静态几何格式。FBX 旁会生成 `.fbx.export.json`，记录网格、骨骼、动画及警告；贴图缺失时可保留模型导出并明确提示。

### 按需预览与内存优化

- 图片、网格、动画、字体、音频等在点击预览／请求导出时加载，不为所有未点击资产预生成预览。
- 打开音频封包只显示媒体列表，不提前解码全部声音；关闭预览释放图像缓冲、GPU 资源、音频与临时字体。
- 小工作区保持独立 worker，大工作区复用已建立索引的 worker，减少同一大型 DB 在内存中的重复副本；同一索引上的操作串行调度。
- 切换／关闭预览会取消或丢弃过时请求；修复连续导出时缓存文件短暂被占用导致的错误提示。

### 资源完整性、音频与其他类型

- 保留连续嵌套 SerializedFile、完整容器索引、包信息、对象身份和来源，避免同名资源跨 DB 混淆；非英雄号命名的 DB 也可以导入。
- 部分解析或失败的对象保留原类别、ClassID、PathID、原始数据及诊断；对象读取受边界限制。
- 完善已支持的 HOK 动画结构、曲线、网格颜色以及结构化元数据解析与导出。
- 完善 BNK/WEM 原始导出与解码校验，支持可解码音频的 WAV／MP3 和封包 ZIP 导出，修复原生音频转换长路径问题。
- 增加 Cubemap 六面预览／PNG ZIP，字体按需预览；关联动画预览加载实际存在的场景依赖，并说明不支持的特效行为。

### 安装与版本信息

- 安装程序识别有效的已有安装记录，默认在原路径升级覆盖，也可选择其他可写目录。
- 覆盖前检查文件占用，升级／卸载保留用户额外放入的文件。
- 程序、worker、安装程序、三语 README、下载文件名统一为 1.4。
- 保留 URL 索引头像、后台静默检查、手动资源同步和中／英／越南文界面。

## 测试结论与边界

- 两组真实 DB 的 8 个网格分别导出 OBJ／FBX，共 16 个文件，独立读取器回读后几何位置、绕序和三角形数量一致，FBX 骨骼权重保留；两组桌面端连续导出通过。
- 6 个合成 FBX 输出验证独立网格、骨骼、动画选择／关闭、根运动和覆盖控制器片段，并实际采样播放。
- 昨晚逐一完成的 20 个 DB 回归：704,337 条可见资产、1,318,295 条容器记录、3,524,080,507 字节恢复内容；载荷哈希与基线一致，原包哈希未改变。
- 本次真实网格样本不含 AnimationClip，不能把合成动画测试表述成“全部真实游戏动画均验证成功”。
- 保留尚未完整解码的原始流和自定义数据，不能宣称所有私有格式已经完整语义解析。缺失依赖、粒子／着色器还原、编解码器兼容仍有边界。
- DB 替换／重建继续标为 **Beta 实验性功能**，不推荐常规使用，未验证游戏内兼容性。

详情见[模型导出验证](../../MODEL-EXPORT-VALIDATION-1.4.md)与[按需预览验证](../../LAZY-PREVIEW-VALIDATION.md)。本地测试通过不代表第三方组件分发许可或安全审查已经完成。
